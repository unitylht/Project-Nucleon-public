PROJECT NUCLEON TEAM TEST PACK
Revision 2 | 18 October 2026 | practice release a9ce30d

1. Extract the ZIP before opening files.
2. Open Nucleon-Team-Testing-Guide.docx.
3. Choose your own folder under testers. In a pair, use one folder for both roles.
4. Read YOUR-TAG.txt. CSV files are already personalised, so do not edit them on your first run.
5. Follow T1 to T7 in order. TAG in the guide means your tag from that file.

Files in each tester folder
01-invoices.csv: import first, then reimport with the SAME source label.
02-payments.csv: import after 01. Includes a partial allocated payment and an unallocated one.
03-invalid-preview-only.csv: preview only, then Close. Do not apply it.
04-revert-only.csv: separate import used only for the reversal task.

The templates folder is optional. Its TESTTAG placeholders MUST be replaced before use.
Do not import every tester folder, and do not upload the ZIP itself. Import individual CSV files.

Access codes are supplied privately by Hanting. No passwords are included.
Do not reset or restore the shared demo, change shared settings, confirm completeness for all customers, or modify another person’s records.
Leave your tagged test records and feedback for review.

Repeat run
Copy one folder. In all four CSVs replace its existing tag with a new unique tag, using a plain-text editor. Use the new tag in the manual tasks too. Preserve UTF-8 text and the .csv extension.
