# Week 7 Core Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Lab runs the agreed Week 7 flow end to end on a real imported ledger: usable import (unit, references, state), honest retrieval, a fixed numerical pipeline exposed as a tool, recommendation separate from authority, staff acting within configured limits or escalating, and decisions retained with their source and feedback.

**Architecture:** The records server (stdlib) owns the data rules: the current-hint tolerance, the unit detection and refusal, description references and allocation counts, the live proposal state, the ledger replay (`prototype/behaviour.py`), `assessRequest`, the owner's authority settings and `actWithinAuthority`. The Lab service adds code-level honesty for failed tools, dataset boundaries per thread, the new tools and prompt rules; the Lab UI renders the import card and the assessment from live state and gives the owner an Authority panel.

**Tech Stack:** as the earlier Lab plans (Python 3.12 stdlib records; Lab venv with pydantic-ai-slim 2.58.0; assistant-ui 0.15.30 + Vite; Playwright checks).

**Spec:** `docs/superpowers/specs/2026-10-21-week7-core-flow-design.md` (§3.1–3.6, §4, §5). Team inputs: `docs/reviews/2026-10-21-team-meeting-and-model-review.md`.

## Review Focus

1. A thread whose focus customer was deleted by a reset: every tool still works, the result carries the note, and the Lab's reply never says the queue is empty when a call failed. (Tasks 1, 4.)
2. An NTK-shaped VND ledger proposed into an AUD workspace is refused with nothing written; the same ledger into a VND (scale 0) workspace writes integer minor units and shows no decimals. (Task 2.)
3. A payment naming an invoice larger than it, two invoices, or no invoice: matched, flagged-unallocated, unallocated, with the counts on the card and the customer balance unchanged by matching. (Task 2.)
4. With no authority settings every assessment escalates; with limits set, a case with nothing overdue and a request within the day limit is `approve_within_authority`, and staff can act exactly then and never otherwise (409 with the failing check). (Task 3.)
5. The same file proposed twice: the second proposal is `duplicate` and the card has no Import button after a reload; Import pressed twice returns the same batches. (Tasks 2, 5.)
